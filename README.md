# Coalshift website

Czech marketing website for **Coalshift** (a product of coalsoft s.r.o.). Next.js
App Router + React + TypeScript + Tailwind CSS, built as a static export
(`output: "export"`) and hosted on Cloudflare Pages.

Project scope, phase plan and quality profile live in [`docs/`](docs/). Read
[`AGENTS.md`](AGENTS.md) before working in this repository.

## Requirements

- Node.js `24.x` (see [`.nvmrc`](.nvmrc); `nvm use`). npm `11.x`.

## Commands

```bash
npm ci                 # install exact locked dependencies
npm run dev            # local development server (http://localhost:3000)
npm run pages:build    # generate image derivatives, then static build → out/
npm run typecheck      # generate image derivatives + route types, then tsc --noEmit
npm run preview        # serve the built out/ directory with Wrangler (run pages:build first)
```

`npm run pages:build` is also the Cloudflare Pages build command; it produces the
`out/` directory. `npm run preview` serves an **already built** export — run
`npm run pages:build` first.

## Images

The two registered raster assets use a build-time Sharp pipeline and the
[`ResponsiveImage`](app/components/ResponsiveImage.tsx) component. SVGs and
logos retain `next/image` with global `images.unoptimized`; no runtime image
optimizer is required by the static export.

- [`image-registry.json`](image-registry.json) records sources, native dimensions,
  public output location and derivative widths.
- [`scripts/generate-image-derivatives.mjs`](scripts/generate-image-derivatives.mjs)
  creates WebP derivatives in `public/img/derivatives/` and validates dimensions.
  Outputs are git-ignored and regenerated by `dev`, `build`, `pages:build` and
  `typecheck`.
- `ResponsiveImage` emits each generated width as its actual `srcset` descriptor.
  The phone and portrait callers supply their responsive `sizes` values.

## Deployment

Production is the `cloudflare-deploy` branch; preview work happens on `redesign`.
Deployment is performed by Cloudflare Pages on push — not from this repository.
