# Coalshift website

Czech marketing website for **coalshift** (a product of coalsoft s.r.o.).
Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS, built as a static
export (`output: "export"`) and hosted on Cloudflare Pages.

## Requirements

- Node.js `24.x` — see [`.nvmrc`](.nvmrc) (`nvm use`), pinned to `24.20.0`. npm `11.x`.

## Commands

```bash
npm ci                 # install exact locked dependencies
npm run dev            # local dev server (http://localhost:3000)
npm run pages:build    # generate image derivatives, then static build → out/
npm run typecheck      # image derivatives + route types, then tsc --noEmit
npm run preview        # serve the already-built out/ with Wrangler (run pages:build first)
```

`npm run pages:build` is also the Cloudflare Pages build command; it produces
`out/`. Full build chain, environment and release procedure:
[`docs/operations.md`](docs/operations.md).

## Images

The two contact-portrait raster assets use a build-time Sharp pipeline and the
[`ResponsiveImage`](app/components/ResponsiveImage.tsx) component. SVGs and logos
render as ordinary `<img>` elements; `next/image` is not used anywhere and the
static export ships no runtime image optimizer.

- [`image-registry.json`](image-registry.json) records sources, native
  dimensions, output location and derivative widths.
- [`scripts/generate-image-derivatives.mjs`](scripts/generate-image-derivatives.mjs)
  writes WebP derivatives to `public/img/derivatives/` (git-ignored) and
  validates dimensions. Regenerated by `dev`, `build`, `pages:build`, `typecheck`.
- `ResponsiveImage` emits each generated width as its real `srcset` descriptor;
  the portrait callers supply their layout-aligned `sizes`.

## Deployment

Production is the `cloudflare-deploy` branch; preview work happens on `redesign`.
Cloudflare Pages builds and deploys on push — not from this repository. The
release sequence, branch fast-forward mechanics and rollback are in
[`docs/operations.md`](docs/operations.md).
