# Coalshift — Quality profile

## Context and reference basis

This profile covers the Czech marketing website with four public content routes, retained source for three unavailable legacy routes, their required redirects, the owner-retired healthcare redirect, the static Cloudflare Pages build, the shared design system, the real product gallery and the final Microsoft Bookings/YouTube integrations. It is the canonical definition of quality requirements; phases refer to the IDs below. It does not certify the separate Coalshift application.

Selection follows the shared web-quality skill and workflow version 1.2, dated 2 September 2026. Relevant modules considered: content/SEO, technical SEO, responsive UI, accessibility, media/performance, forms, analytics/consent, security/privacy, maintainability and release verification. The requirements below are standalone; access to the shared skill folder is not needed to interpret them.

Primary sources opened during discovery on 2 September 2026:

- [Next.js static exports](https://nextjs.org/docs/app/guides/static-exports) and [Cloudflare static Next.js deployment](https://developers.cloudflare.com/pages/framework-guides/nextjs/deploy-a-static-nextjs-site/): `out` is the selected static output; the default runtime image optimizer is not supplied by static export.
- [Cloudflare preview branch controls](https://developers.cloudflare.com/pages/configuration/branch-build-controls/) and [preview deployments](https://developers.cloudflare.com/pages/configuration/preview-deployments/): provider behavior to verify against the actual project settings and deployed version.
- [Next.js August 2026 security release](https://nextjs.org/blog/august-2026-security-release): patched releases 15.5.24 and 16.3.3 were published. Select a currently supported compatible release in phase 01; these numbers are dated observations, not instructions to install an older version later. [Earlier RSC advisory](https://nextjs.org/blog/CVE-2025-66478) does not by itself prove exploitability of this static production website.
- [WCAG 2.2 contrast guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) and [reflow guidance](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): basis for the selected interface checks. This project does not claim a full WCAG certification.
- [Reduced-motion guidance](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html): reduced-motion support is a project requirement. The linked interaction criterion is AAA; it is not presented as a blanket AA requirement.
- [MPSV Labour Code reference](https://ppropo.mpsv.cz/zakon_262_2006), [breaks](https://ppropo.mpsv.cz/VIII4Prestavkavpraciabezpecnostn) and [daily rest](https://ppropo.mpsv.cz/viii81nepretrzitydenniodpocinek): support correction of the PDF's inaccurate section reference, not a legal audit of the product.
- [Microsoft Bookings FAQ](https://learn.microsoft.com/en-us/microsoft-365/bookings/bookings-faq?view=o365-worldwide) and [language/time-zone settings](https://learn.microsoft.com/en-us/microsoft-365/bookings/set-language-time-zones?view=o365-worldwide): support an iframe plus direct public link and a Czech self-service page.
- [YouTube privacy-enhanced embeds](https://support.google.com/youtube/answer/171780): use `youtube-nocookie.com`; the owner supplies one unlisted embeddable video.
